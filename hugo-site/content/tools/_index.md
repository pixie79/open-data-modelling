## Open Data Modelling Tools

Open Data Modelling provides a comprehensive suite of tools and applications for creating,
managing, and working with data contracts and schemas. Whether you're a developer building
data pipelines, a data engineer managing schemas, or a business user working with data
models, we have tools to meet your needs.

## Available Tools

### Data Modelling SDK

A powerful software development kit for integrating data contract functionality into your
applications. Build custom tools and workflows with our comprehensive API.

[Learn more about the SDK →](/tools/sdk/)

### Data Modelling API

A RESTful API service for managing data contracts, schemas, and validations. Perfect for
server-side applications and microservices architectures.

[Learn more about the API →](/tools/api/)

### OSX App

A native macOS application for creating, editing, and managing data contracts with an
intuitive graphical interface. Perfect for Mac users who prefer desktop applications.

[Learn more about the OSX App →](/tools/osx-app/)

### Web App

A modern web-based application accessible from any browser. Create and manage data contracts
from anywhere with our responsive web interface.

[Learn more about the Web App →](/tools/web-app/)

## Getting Started

1. **Choose Your Tool**: Select the product that best fits your workflow
2. **Review Documentation**: Check the product-specific pages for detailed information
3. **Access the Repository**: Visit the GitHub repository to get started
4. **Start Building**: Follow the setup instructions to begin using the tool
