## Usage Guides

Learn how to use Open Data Modelling tools effectively with our comprehensive guides. Whether
you're importing existing schemas, exporting contracts, working with Crowsfeat notation, or
designing data flows, these guides will help you get the most out of the platform.

## Available Guides

### Import

Learn how to import existing schemas and data contracts from various formats into Open Data
Modelling. Support for JSON Schema, Avro, Protobuf, and more.

[Import Guide →](/guides/import/)

### Export

Export your data contracts and schemas to different formats for use in other systems. Support
for multiple output formats and customization options.

[Export Guide →](/guides/export/)

### Crowsfeat Notation

Understand Crowsfeat notation, a powerful way to represent data structures and relationships
in a concise, readable format.

[Crowsfeat Guide →](/guides/crowsfeat/)

### Data Flows

Learn how to design and document data flows, and understand how they relate to data models.
Create visual representations of data movement and transformation.

[Data Flows Guide →](/guides/data-flows/)

## Getting Started

1. **Choose a Guide**: Select the guide that matches your needs
2. **Follow the Steps**: Step-by-step instructions with examples
3. **Try It Yourself**: Use the examples to practice
4. **Explore Further**: Check related guides and documentation
