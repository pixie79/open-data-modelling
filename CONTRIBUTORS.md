Contributors are recognized for their:

- Code contributions
- Documentation improvements
- Bug reports and fixes
- Feature suggestions
- Community support

## Adding Yourself

If you've contributed to the project and would like to be listed here, please:

1. Add your name and contribution details to this file
2. Submit a pull request
3. Follow the same format as existing entries

Example entry:

```markdown
- **Your Name** - Contribution description
  - GitHub: [@yourusername](https://github.com/yourusername)
  - Contributions: Feature X, Bug fix Y, Documentation Z
```

## Code of Conduct

All contributors are expected to:

- Be respectful and inclusive
- Follow project quality standards
- Provide constructive feedback
- Help maintain a positive community

Thank you for contributing to Open Data Modelling!
