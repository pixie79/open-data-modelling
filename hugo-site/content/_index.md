## Welcome to Open Data Modelling

Open Data Modelling provides tools, standards, and best practices for creating, managing, and sharing data contracts and schemas. Our mission is to make data contracts accessible, standardized, and easy to implement.

Open Data Modelling is built on open standards maintained by [Bitol](https://bitol.io/), including the Open Data Contract Standard (ODCS) and Open Data Product Standard (ODPS). These standards provide a foundation for consistent, interoperable data management across organizations and systems.

## What You'll Find Here

### Data Contracts

Learn about data contracts and why they matter for data quality, reliability, and collaboration. Data contracts define the structure, format, and expectations for data exchange between systems.

[Learn more about Data Contracts →](/data-contracts/)

### Open Data Contract Standard (ODCS)

Discover the Open Data Contract Standard, a comprehensive framework for defining and managing data contracts. ODCS provides a standardized approach to data contract specification, validation, and governance. ODCS is maintained by Bitol as an open standard.

[Explore ODCS →](/odcs/)

### Open Data Product Standard (ODPS)

Learn about the Open Data Product Standard, a framework for defining and cataloging data products. ODPS enables organizations to create searchable data product catalogs and standardize data product definitions. ODPS is also maintained by Bitol as an open standard.

[Explore ODPS →](/odps/)

### Data Governance

Understand best practices for data governance, including data quality management, cataloging, access control, and compliance. Learn how open standards like ODCS and ODPS support effective data governance.

[Learn about Data Governance →](/data-governance/)

## Tools and Applications

Open Data Modelling provides a comprehensive suite of tools and applications to help you work with data contracts and schemas:

### Benefits of Using Our Applications

Our tools and applications provide significant benefits for teams working with data contracts:

- **Visual Interface**: Create and edit data contracts using intuitive graphical interfaces, making it accessible to both technical and non-technical users
- **Real-Time Validation**: Validate data contracts and schemas in real-time as you work, catching errors early
- **Standards Compliance**: Built-in support for ODCS and ODPS standards, ensuring consistency across your organization
- **Collaboration**: Share and collaborate on data contracts with team members
- **Version Management**: Track changes and manage versions of your data contracts
- **Export Flexibility**: Export to multiple formats (JSON Schema, Avro, Protobuf, etc.) for use in different systems
- **Integration**: SDK and API options for integrating data contract functionality into your existing workflows

### Available Tools

- **[SDK](/tools/sdk/)** - Integrate data contract functionality into your applications
- **[API](/tools/api/)** - Server-side service for managing data contracts
- **[OSX App](/tools/osx-app/)** - Native macOS application with a rich graphical interface
- **[Web App](/tools/web-app/)** - Browser-based application accessible from anywhere

## Why Data Contracts Matter

Data contracts ensure:

- **Reliability**: Consistent data structure across systems
- **Quality**: Validation and enforcement of data standards
- **Collaboration**: Clear expectations between data producers and consumers
- **Evolution**: Safe schema changes with versioning and compatibility
