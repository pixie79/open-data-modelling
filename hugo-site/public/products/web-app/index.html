Web App

Modern web-based application for creating and managing data contracts from any browser

Web App

The Open Data Modelling Web App is a modern, responsive web application that allows you to create and manage data contracts from any device with a web browser. No installation required - just open your browser and start working.

Features

Browser-Based Interface

  • Responsive design for desktop, tablet, and mobile
  • Works in all modern browsers
  • No installation or updates required
  • Cross-platform compatibility

Contract Management

  • Create and edit data contracts online
  • Cloud storage and synchronization
  • Version control and history
  • Collaboration features

Visual Tools

  • Drag-and-drop schema builder
  • Real-time validation
  • Visual data flow diagrams
  • Export to multiple formats

Accessibility

  • Keyboard navigation support
  • Screen reader compatible
  • High contrast mode
  • WCAG 2.1 Level AA compliant

Getting Started

Access the Web App

Simply navigate to the web app URL in your browser. No account required for basic features, sign up for cloud storage and collaboration.

Quick Start

  1. Open the App: Navigate to the web app URL
  2. Create a Contract: Click “New Contract” to begin
  3. Design Your Schema: Use the visual editor
  4. Test Validation: Try validating sample data
  5. Save & Share: Save your work and share with your team
