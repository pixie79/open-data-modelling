## Standards

Open Data Modelling is built on open standards maintained by [Bitol](https://bitol.io/). These standards provide a foundation for consistent, interoperable data management across organizations and systems.

## Open Data Contract Standard (ODCS)

The Open Data Contract Standard (ODCS) is a comprehensive framework for defining, managing, and validating data contracts. ODCS provides a standardized approach to data contract specification, validation, and governance.

[Learn more about ODCS →](/odcs/)

## Open Data Product Standard (ODPS)

The Open Data Product Standard (ODPS) is a framework for defining and cataloging data products. ODPS enables organizations to create searchable data product catalogs and standardize data product definitions.

[Learn more about ODPS →](/odps/)

## Why Open Standards?

Open standards provide several key benefits:

- **Interoperability**: Standards ensure that data contracts and products can be used across different tools and platforms
- **Consistency**: Standardized formats reduce confusion and errors
- **Community**: Open standards benefit from community contributions and improvements
- **Vendor Independence**: Standards prevent vendor lock-in and enable tool choice
